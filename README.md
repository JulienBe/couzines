# Cousinade 2026 — activités autour d'Aunou

Sorties repérées en Orne, Calvados, Sarthe et Mayenne pour l'été 2026.

- `activites.md` — les notes brutes, source de vérité.
- `index.html` — la version web : fiches filtrables, carte de repérage et journées types.

En ligne : https://julienbe.github.io/couzines/

La page est autonome (aucune dépendance externe) : `index.html` s'ouvre aussi en local.
Les coordonnées de la carte viennent de Nominatim / OpenStreetMap ; les distances sont
à vol d'oiseau depuis Aunou-sur-Orne.
